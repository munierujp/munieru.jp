# こだわりポイント

閲覧する端末や言語が違っても、内容を読みやすく、操作しやすくするための工夫をまとめます。

## ダークモード対応

システム設定・ライト・ダークを選択でき、選択内容を保存します。テーマごとに配色を定義し、初期描画前にテーマを適用して表示時のちらつきを抑えています。

## レスポンシブデザイン

スマホから広い画面まで、カードの列数や画像・本文の配置を調整します。小さな画面でもプロフィール画像が見えやすく、サービス名が途中で改行されない配置にしています。

## 日本語・英語対応

言語別のURLを用意し、入口ではブラウザの言語や保存した選択に応じて振り分けます。書籍の章名や登壇タイトルは原題を残し、英語版には参考英訳を添えています。

## タップしやすいリンク

カード全体を主リンクの操作領域にし、作品のGitHubリンクと、登壇のイベント情報へのリンクは独立させています。作品は公開日の新しい順に全件表示します。

## アクセシビリティへの配慮

言語・テーマのメニューはキーボードで操作でき、フォーカス表示や現在の選択状態を伝えます。アイコンだけのリンク・ボタンには用途が分かる名前を付けています。

## 表示速度と外部リソースへの依存低減

HTMLを静的生成し、画像・アイコンはサイト内から配信します。プロフィール画像や表紙はAVIF・WebPと画面幅に応じた画像候補を生成し、優先読み込み・遅延読み込みを使い分け、フォントは端末搭載の書体を優先しています。

## 検索・共有時の表示

言語別のタイトル・説明・OGP画像に加え、canonical・hreflang・構造化データ・サイトマップを用意しています。OGP画像はサイトと共通の名前・サイト名を使い、実際のフォントで生成します。
