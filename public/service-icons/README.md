| サービス | ファイル | 取得元 |
| --- | --- | --- |
| GitHub Sponsors | `github.svg` | 既存のGitHubリンクで使用しているアイコンを共用 |
| PayPal | `paypal.ico` | https://www.paypalobjects.com/webstatic/icon/favicon.ico |
